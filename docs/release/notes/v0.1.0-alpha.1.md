# Bored Manager v0.1.0-alpha.1

This signed pre-alpha release introduces the first installer-enabled Bored Manager build. It is
intended for isolated lab evaluation, not production workloads.

## Highlights

- Manager, Docker-host, and managed-agent support for Ubuntu 24.04 LTS amd64 and the Kali Linux
  rolling lineage (`kali-rolling` and its frozen `kali-last-snapshot` snapshots).
- A single verified Debian package set for both supported platforms, built with CGO disabled.
- Signed release manifest and checksums, embedded Ed25519 trust root, SPDX SBOM, and GitHub build
  provenance.

## Installation

Prereleases are not selected by GitHub's `/releases/latest` route. After independently verifying
the release-key fingerprint and installer digest, use the exact-tag installer URL documented in
the repository README.

The installer requires amd64, a running systemd instance, and a regular sudo-capable user. Kali
containers without systemd and unsupported Debian-derived distributions are rejected.

## Known limitations

- This remains an early pre-alpha. Features marked planned in the README are not release claims.
- Kali is a rolling distribution; record the tested point-release, APT suite, kernel, systemd,
  dpkg, and Docker versions when reporting a problem.
- Stable-release certification gates have not been completed, so this release must remain marked
  as a prerelease.
